Label 5 real credit-union member reviews yourself, then run the same reviews through two LLMs of your choice and see exactly where each model agrees and disagrees with your judgment.

1 Your labels Not submitted

Read each review and record the sentiment and primary topic before running any model — seeing a model's answer first will quietly bias you. Be consistent rather than perfect: e.g. decide up front that "mixed" only applies when there is real praise and real criticism.

2 Models & API keys

Pick any two models your key(s) can call — a big model against a cheap one is an interesting pairing. Keys are used only in your browser to call the provider's API directly and are never written into this file.
